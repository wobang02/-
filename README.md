# 👑 초등학교 5학년 조선왕조 왕과 업적 카드 짝 맞추기 게임

초등학교 5학년 사회과(역사 영역) 수업 시간에 학생들이 재미있게 조선시대 27대 왕과 주요 업적을 학습할 수 있는 인터랙티브 웹 카드 뒤집기 게임입니다.

---

## 🎮 주요 게임 모드

### 📘 1단계: 시대별 연습 학습 (수업 차시별 활용)
- **🏰 조선 전기 (1~9대)**: 태조부터 성종까지 (조선 건국, 훈민정음 창제, 경국대전 완성)
- **⚔️ 조선 중기 (10~18대)**: 연산군부터 현종까지 (사화, 조광조, 임진왜란, 병자호란)
- **📜 조선 후기 (19~27대)**: 숙종부터 순종까지 (탕평책, 수원화성, 세도정치, 개항)

### 🎲 2단계: 랜덤 실력 테스트 (배운 내용 무작위 도전)
- **🟢 난이도 하 (초급)**: 27대 왕 중 무작위 6쌍 (12장) - 3×4 그리드
- **🟡 난이도 중 (중급)**: 27대 왕 중 무작위 10쌍 (20장) - 4×5 그리드
- **🔴 난이도 상 (도전)**: 27대 왕 중 무작위 15쌍 (30장) - 5×6 그리드
- **👑 전체 마스터**: 27대 왕 전체 27쌍 (54장)
